# MaestroPro

MaestroPro es una aplicación web educativa de demostración para organizar actividades docentes.

## Abrir el proyecto

1. Extrae el archivo ZIP completo.
2. Abre la carpeta `MaestroPro-Nuevo` en Visual Studio Code.
3. Abre `index.html` con Live Server o desde un navegador compatible.
4. Mantén juntas las carpetas `css` y `js`; la aplicación las necesita para funcionar.

## Código fuente

- `index.html`: estructura de la aplicación.
- `css/styles.css`: estilos y diseño adaptable.
- `js/app.js`: navegación, módulos y lógica de la aplicación.
- `GUIA-DE-PRESENTACION.md`: guía para explicar el proyecto.
- `LEEME.txt`: instrucciones breves de uso.

## Datos y privacidad

La versión de demostración guarda información en el almacenamiento local del navegador. Utiliza únicamente datos ficticios para pruebas y exposiciones. No está diseñada para almacenar información personal o académica real sin una solución de seguridad y administración adecuada.
